# Principles

`config/docs/principles` contains `common.md`, `narratives.md`, and one checklist per authored layer. Every selected file answers every H2 item.

## Form

- Use one H1, brief scope prose, and one fixed-anchor H2 per item. Add no deeper heading.
- Ask one independently falsifiable, actionable question per item. Conditional facets may stay together only when they test the same target; split a second target that can be applied, refuted, changed, repaired, or reviewed independently. If the same host reason necessarily answers two items, merge them or state their boundary.
- End every H2 with a `Sources:` line. Use [references.md](references.md) first, then verify each link separately.

## Admission

Add an item only when it is subject- and genre-independent, supported by scholarship and established practice, absent from existing items, and expressible with its own condition. Put it in the narrowest layer file that owns it.

Principles never allow exclusion. State limits inside the item; a host that cannot truthfully claim compliance is defective.

## Change

Editing an item expires every host answer to it. Reread the changed item against each host before renewing its review; never replace only the fingerprint.
