# Shared Evidence Obligations

`config/docs/obligations` contains one target file per owning layer. The [evidence graph skill](../evidence-graph/SKILL.md) owns host populations, cardinality, exclusions, stages, and reviews.

## Form

- Use one H1, one fixed-anchor H2 per role, and no deeper heading. Keep H1 prose to essential scope.
- State the role only; do not copy graph behavior into the target.
- End every H2 with scholarly or established-practice sources.

## Admission

Test valid counterforms before adding a role. Put a universal function under its owning layer. A form-specific role belongs here only when the graph permits one population-wide exclusion and the text admits equivalent realizations.

Keep work-specific roles in the package and unproven candidates in `.wiki`. Do not create an obligation file for a layer with no independent target.
