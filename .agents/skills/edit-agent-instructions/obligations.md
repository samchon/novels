# Shared Evidence Obligations

`config/docs/obligations` contains `common.md` for obligations every authored unit answers and one target file per layer for roles every complete layer population must cover. The [evidence graph skill](../evidence-graph/SKILL.md) owns host populations, cardinality, stages, and reviews.

## Form

- Use one H1, one fixed-anchor H2 per obligation, and no deeper heading. Keep H1 prose to essential scope.
- State one independently falsifiable target and its boundary. Conditional manifestations may vary by host type, and one distributed role may span several hosts; split a second duty or role that can be acknowledged, omitted, changed, repaired, or reviewed independently in the same population. In `common.md`, also state observable failures and the repair or halt required before acknowledgement. In a distributed-role file, define the required role. Do not copy TypeScript configuration or tag grammar into the target.
- End every H2 with scholarly or established-practice sources.

## Admission

Put a subject- and genre-independent duty that every settings H2 and narrative H2/H3/H4 must satisfy in `common.md`; its reference is a no-exclusion checklist. Use it for a unit-level completion or evidence-integrity duty whose explicit evidence and remediation must survive agent summarization, not for a duplicate of a file-level literary principle.

Add a shared distributed role only when every complete work must give it some host, put it under its owning layer, and configure it with no exclusion. A role a valid work may omit belongs in its package when work-specific or in `.wiki` while unproven. Do not create an obligation file for a layer with no independent target.
