# References

Every external source the settings canon cites, grouped by what kind of evidence it is. Generated from the `Sources:` lines in `docs/settings`, so it follows the canon rather than standing beside it: a citation that changes there changes here.

This directory holds no canon. Nothing in `docs/settings` cites it, and it answers no principle checklist. It is a map of the evidence, kept so the sourcing standard in `principles/settings.md#canon-and-sources` can be audited at a glance.
